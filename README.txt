نور يومي V2 — حزمة PWA

الملفات:
- index.html: التطبيق
- manifest.webmanifest: بيانات التثبيت والأيقونة
- sw.js: التخزين المؤقت والعمل دون اتصال بعد أول زيارة
- icon.svg: أيقونة التطبيق

طريقة النشر:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub.
2) من Settings > Pages اختر Deploy from a branch.
3) اختر الفرع main والمجلد /(root)، ثم Save.
4) انتظر رابط GitHub Pages الذي يبدأ بـ https://.
5) افتح الرابط على هاتف Android باستخدام Chrome.
6) من قائمة ⋮ اختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".

ملاحظات:
- تثبيت PWA يحتاج إلى HTTPS (GitHub Pages يوفره).
- افتح الرابط مرة مع الإنترنت قبل استخدامه دون اتصال.
- ملفات الصوت والروابط الخارجية تحتاج إلى الإنترنت/دعم المتصفح.
- هذه حزمة PWA وليست APK.
